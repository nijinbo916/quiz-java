# Quiz 前后端 Ubuntu（VirtualBox）部署手册

> 对应课件 11-13 任务第 2 步与《Quiz前后端管理验收条件书》第 2 条。
> 线下验收从下周开始，虚拟机要长期保存好快照。

## 0. 系统构成

| 组件 | 技术 | 端口 | 部署位置 |
| --- | --- | --- | --- |
| 管理端前端 | Vue 2 + Element UI（dist 静态产物） | 8081 | `/var/www/quiz-admin` |
| 用户端前端 | html/css/js（quiz-game） | 80 | `/var/www/quiz-user` |
| Java 后端 | Spring Boot jar | 8080 | `~/apps/quiz/` |
| 数据库 | MySQL 8 | 3306 | Ubuntu 本机 |
| 反向代理 | Nginx | 80 / 8081 | 接口请求由 Nginx 转发到 8080，同源无跨域 |

## 1. 准备虚拟机

1. 安装 VirtualBox + 下载 Ubuntu 22.04 Server ISO，新建虚拟机（2 核 4G、30G 硬盘、NAT 网络）。
2. 装完后在 VirtualBox「设置 → 网络 → 高级 → 端口转发」加两条规则，宿主机才能访问：
   - 主机端口 `8081` → 子系统端口 `8081`（管理端）
   - 主机端口 `80` → 子系统端口 `80`（用户端）
3. 装基础软件：

```bash
sudo apt update
sudo apt install -y openjdk-17-jdk mysql-server nginx
sudo systemctl enable --now mysql nginx
```

## 2. 迁移数据库

Windows 上已导出 `deploy/quiz.sql`（含 user 11 条、questions 12 条，密码已加密）。
通过共享文件夹或 `scp` 传到虚拟机后：

```bash
# 进入 mysql，创建业务账号（不要用 root 跑应用）
sudo mysql
```

```sql
CREATE DATABASE IF NOT EXISTS quiz DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
CREATE USER IF NOT EXISTS 'quizuser'@'localhost' IDENTIFIED BY 'quiz12345';
GRANT ALL PRIVILEGES ON quiz.* TO 'quizuser'@'localhost';
FLUSH PRIVILEGES;
EXIT;
```

```bash
mysql -u quizuser -p --default-character-set=utf8mb4 < quiz.sql
mysql -u quizuser -p -e "select count(*) from quiz.user; select count(*) from quiz.questions;"
```

## 3. 部署 Java 后端

```bash
mkdir -p ~/apps/quiz && cd ~/apps/quiz
# 把 quiz-0.0.1-SNAPSHOT.jar、application-ubuntu.yml、app 运行日志都放这里
cp quiz-0.0.1-SNAPSHOT.jar .
cp application-ubuntu.yml application.yml   # 改名后与 jar 同级，会覆盖包内配置
nohup java -jar quiz-0.0.1-SNAPSHOT.jar > app.log 2>&1 &
tail -f app.log                              # 看到 Started QuizApplication 即成功
curl http://localhost:8080/hello             # 验证
```

注意：
- jar 包内已经带了本地开发用的 application.yml（root/123456），用**同目录的
  application.yml 覆盖它**，不要把本地库密码带上服务器。
- 防火墙不用放行 8080——后端只服务给 Nginx，8080 不对外。

## 4. 部署两个前端

```bash
# 管理端：本地 quiz-admin/dist 目录里的所有文件 → /var/www/quiz-admin
sudo mkdir -p /var/www/quiz-admin /var/www/quiz-user
sudo cp -r dist/* /var/www/quiz-admin/

# 用户端：quiz-game 仓库的全部网页文件 → /var/www/quiz-user
sudo cp index.html login.html register.html /var/www/quiz-user/
sudo cp -r css js /var/www/quiz-user/
```

**重要**：用户端要改成同源访问——编辑 `/var/www/quiz-user/js/config.js`：

```js
window.QUIZ_API_BASE = '';   // Ubuntu 上走 Nginx 同源代理
```

（Windows 本机联调时保持 `http://localhost:8080` 不变。）

## 5. 配置 Nginx

```bash
sudo cp nginx-quiz.conf /etc/nginx/conf.d/quiz.conf
sudo rm -f /etc/nginx/sites-enabled/default    # 可选：去掉默认站点，避免 80 端口冲突
sudo nginx -t
sudo systemctl reload nginx
```

## 6. 验收自检清单（对应条件书 checkpoints）

| 功能点 | 操作 |
| --- | --- |
| 用户端注册用户 | 浏览器开 `http://localhost/register.html`，注册一个新号 |
| 用户端登录 | `http://localhost/login.html`，用新号登录，跳到答题页 |
| 用户端做题 | 开始挑战 → 题目来自后端 → 交卷出结果 |
| 管理端登录 | `http://localhost:8081`，admin/123456 能进；用普通用户登录会被拒（invalid account） |
| 区分角色添加用户 | 用户管理 → 添加用户 → 角色选普通用户/管理员 |
| 删除用户 | 用户管理 → 删除 / 批量删除 |
| 重置用户密码 | 用户管理 → 重置密码 → 用户端用 123456 能登录 |
| 添加/删除题目 | 题目管理 → 新增、删除 |
| 修改题目 | 题目管理 → 编辑，改题干/选项/答案 |
| 关键词查询 | 用户管理和题目管理的关键词搜索 |
| 分页查看 | 两个页面的分页控件 |

宿主机访问地址（端口转发后）：`http://localhost:8081`（管理端）、`http://localhost/`（用户端）。

## 7. 常见问题

- **jar 起不来报 Access denied**：application.yml 的账号密码和第 2 步创建的 quizuser 不一致。
- **页面 502**：`systemctl status nginx` + `tail app.log`，后端多半没起来。
- **题目能看但登录 404**：Nginx 的 location 正则里漏了对应路径，对照 `nginx-quiz.conf`。
- **管理端白屏**：dist 是 hash 路由，确认 `try_files ... /index.html` 没被去掉。
